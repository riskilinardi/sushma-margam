# Margam · Sushma Sekaran

Website for Sushma's Bharatanatyam Margam on 5 December 2026 at Nrityalaya Aesthetics Society, Singapore.

## Running it

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Where things live

- `src/content/` holds the words on the site: event details now, programme and lyrics later. Change text here, not in the components.
- `src/components/` holds the sections of the page, grouped by feature (`intro`, `hero`, …), with shared pieces in `ui`.
- `src/app/globals.css` has the colour palette and fonts.

Run `npm run format` before committing.
